# Plan 10 — apply to the live machine + remove external token-sinks

[Index](00-INDEX.md) · Wave E · SUPERVISED — this plan mutates live machine
state under `~/.claude` and `/tmp`. Every step: back up first, show before/after.
Depends on plans 01, 02, 03, 05, 06 being in the working tree.

## Context

The repo fixes don't reach sessions until rendered. Additionally, two
externally-installed hooks (from codebase-memory-mcp, NOT this repo) measurably
work against the token goal: `cbm-code-discovery-gate` caused 96 blocked tool
calls across 88 transcripts (a full wasted model round-trip each; its `/tmp`
GC is broken on macOS — `find /tmp` never descends the symlink), and
`cbm-session-reminder` injects ~900 bytes (~230 tokens) at EVERY SessionStart/
resume/compact — outside the repo's prefix budget. The session skill list also
carries three vague duplicates from the `anthropic-skills` plugin
(`terminal-command-usage-with-rtk`, `gitnexus`, `lean-ctx`) that shadow the
repo's curated skills. Finally, today's `~/.claude/settings.json` contains a
duplicate shell-guard group + a standalone absolute-path
`/opt/homebrew/bin/lean-ctx hook rewrite` (pre-plan-03 merge drift).

## Steps

### 1. Snapshot

`cp ~/.claude/settings.json ~/.claude/settings.json.bak-reviewfix-$(date +%Y%m%d%H%M%S)`
and the same for `~/.claude.json` and `~/.claude/agentic-cfg.generated.md`.
List the backups.

### 2. Rebuild + install

- `go build -o bin/agentic ./cmd/agentic` (repo root).
- `bash bin/install.sh --provider claude` (strong tier — this machine keeps
  lean-ctx). Then `bash bin/install.sh --provider cursor`.
- Expected effects to verify:
  a) `~/.claude/agentic-cfg.generated.md` regenerated, size ≤ 9,000 bytes
     (post plan 05), content starts with the stub header;
  b) `~/.claude/settings.json`: exactly ONE hook group per managed matcher —
     `jq '[.hooks.PreToolUse[].matcher, .hooks.PostToolUse[].matcher]'` shows
     the plan-02 anchored patterns once each; the standalone
     `/opt/homebrew/bin/lean-ctx hook rewrite` group is GONE (plan 03 merge);
     machine-local `env` keys preserved byte-identical (diff against backup);
  c) `claude mcp list` (or jq on `~/.claude.json`) still shows the same
     server set as before (gitnexus, lean-ctx, codebase-memory…), no
     hand-added server lost.

### 3. Remove the cbm hook round-trip sinks (external, reversible)

In `~/.claude/settings.json`, delete the hook entries whose command paths
contain `cbm-code-discovery-gate` and `cbm-session-reminder` (they are
user-scope entries added by codebase-memory-mcp; the MCP server itself and all
its tools STAY registered and usable). Record in the report the exact JSON
removed, so restoring is one paste from the backup. Also delete stale gate
marker files: `find /tmp/ -maxdepth 1 -name 'cbm-code-discovery-gate-*' -delete`
(note the trailing slash — required on macOS).
If a `~/.claude/hooks/cbm-*` file is regenerated by the MCP on next start,
that's fine — only the settings registration gates behavior; note whether the
files remain on disk.

### 4. Disable the three duplicate plugin skills

Locate the anthropic-skills plugin install (likely under
`~/.claude/plugins/…anthropic-skills…` — find via
`grep -rl "terminal-command-usage-with-rtk" ~/.claude/plugins/ 2>/dev/null` or
the plugin registry file). Preferred mechanism, in order:
 a) a per-skill disable in plugin/settings config if one exists;
 b) otherwise rename each of the three skill directories
    (`terminal-command-usage-with-rtk`, `gitnexus`, `lean-ctx`) to
    `<name>.disabled` inside the plugin, and note they may return on plugin
    update (add a line to `catalog/plugins.yaml` comment documenting this).
Do NOT touch the plugin's other skills (docx/pdf/pptx/xlsx/schedule/…).

### 5. Doctor + prefix accounting

- `bash bin/doctor.sh --deep` — clean.
- Report the new always-on arithmetic: generated.md bytes (target ≤ 9,000),
  vs the pre-wave 11,232; note that the ~230-token cbm session reminder and
  ~3×60-word duplicate skill descriptions are now gone as well.

## Acceptance criteria

1. All three backups exist and are listed in the report.
2. Step-2 checks a–c all shown with command output (jq/diff), all passing.
3. `grep -c 'cbm-code-discovery-gate\|cbm-session-reminder' ~/.claude/settings.json` → 0;
   `ls /tmp/cbm-code-discovery-gate-* 2>/dev/null` → empty.
4. The three duplicate skills are not discoverable: the plugin dir shows them
   disabled/renamed, and `grep -rn "Use for getting context"` under the plugin
   skills dir finds nothing active.
5. `bash bin/doctor.sh --deep` exits 0.
6. A fresh `claude -p --model claude-haiku-4-5-20251001 "reply OK"` launches
   without hook errors (smoke that the edited settings.json parses and hooks fire).
7. Report ends with a delta table: prefix bytes before/after, hook processes
   per Bash call before/after (was 4–5), per-session injected reminders
   removed (~230 tok), duplicate skill descriptions removed (~180 words).

## Rollback

Every mutation has a timestamped backup from step 1; restoring is
`cp <backup> <target>`. The plugin skills are restored by removing the
`.disabled` suffix. Stale `/tmp` markers regenerate harmlessly.
