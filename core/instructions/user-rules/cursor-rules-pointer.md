# Cursor user rules pointer

Cursor **User Rules** (Settings → Rules) are stored in the cloud and are not fully mirrored on disk.

After `bin/install.sh`, add or update a short User Rule in Cursor:

> Personal agent config: your agentic-cfg clone root (e.g. ~/Documents/GitHub/agentic-cfg). Follow `core/instructions/AGENTS.md`. Use skills in `core/skills/` (symlinked to `~/.cursor/skills`). For git commits, PRs, code graph navigation (codebase-memory), and shell commands, invoke the matching skills. Marketplace plugins: see `catalog/plugins.yaml`.

Skills and `AGENTS.md` are the portable source of truth; this pointer keeps Cursor UI aligned with the repo.
